Skipping Rules

Short, clear board game tutorials on video, produced with my own system that turns a rulebook into videos with animation, voice-over and subtitles.

Watch the channel↗

The challenge

Learning a new board game usually means reading a long rulebook or watching half-hour videos. I wanted short explanations, faithful to the official rules and in several languages.

The solution

My own system starts from the official rulebook and produces each rule as a clip: reviewed script, code-animated demonstrations with Remotion, voice-over and subtitles. The same material is reframed into the full landscape tutorial.

Results

  • Each rule as a vertical clip; the full tutorial in landscape
  • Spanish and English from the same material
  • Demonstrations animated in code, no table filming
  • No tricks: just explain it well
  • Remotion
  • TypeScript
  • Python
  • Voice-over
